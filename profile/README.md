UltraISO 9.7.6.3860 is developed by EZB Systems, and it’s an ISO image creation, editing, and conversion tool with a bootable CD/DVD/USB maker built in. What sets it apart from a simple disc-burning utility is direct ISO editing, most tools require extracting an image, modifying the files, then repacking everything from scratch, while UltraISO lets you add, delete, and modify files inside an ISO directly, preserving the image’s integrity throughout rather than rebuilding it. PowerISO Portable covers similar territory in a no-install format, worth knowing about if you specifically don’t want to run a full installer.

Format support is genuinely broad: ISO, CUE, BIN, NRG, MDF, MDS, IMG, CCD, UIF, VCD, BWT, DAA, BWI, HFS, DMG, C2D, and IMA are all supported for conversion, along with UltraISO’s own proprietary ISZ format, a compressed image format supporting AES encryption. Worth flagging honestly: security researchers have noted ISZ’s encryption implementation lacks integrity protection and is vulnerable to a specific cryptographic attack (a padding oracle attack), so it’s not a format I’d rely on for genuinely sensitive data, even though it’s convenient for space-saving archival of ordinary disc images.

The AutoSplit feature added a few versions back handles writing bootable UEFI USB drives directly from a Windows 10 or later ISO, and support for UDF ISO images with individual files over 200GB covers modern large-scale disc image needs that older ISO tools weren’t built to handle. Virtual drive support extends to working alongside DAEMON Tools Pro 8, letting UltraISO-created images mount cleanly in that companion virtualization software.
